3D Lab — image → mesh, same rules

The flip at the top is the whole idea: one hub. Drop in an image and a free open model turns it into a real 3D mesh — a GLB that drops straight into Unity / Unreal / Godot. No signup, no key required, and in AUTO mode the hub switches provider itself if one fails — same deal as the 2D side.

Drop an image here or click to pick one
PNG / JPG — one subject on a plain background works best

The 3D spaces run on shared free GPUs (ZeroGPU). Anonymous runs work while quota lasts; a free token raises YOUR quota and is the fix the spaces themselves suggest. Get one at huggingface.co/settings/tokens (Read token). Stored in this browser's localStorage, never on a server — shared with the 2D HF model key, and sent only to the provider you run.
